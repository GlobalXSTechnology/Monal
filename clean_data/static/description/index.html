Mass Clean Data(Clear data)

This module will help you to clean unwanted data.

Explore this module

Overview Key Features Setup & Configuration Screenshots

Overview

This module allows user to clear the unwanted data using wizard.

Features

Module helps the user to clear unwanted testing data using wizard on single click of a button.

Available options for data cleaning.

  • Sales & All Transfers
  • Purchase & All Transfers
  • Only Transfers
  • All Invoicing, Payments & Journal Entries
  • Only Journal Entries
  • Customers & Vendors
  • Chart Of Accounts & All Accounting Data
  • Project, Tasks & Timesheet
  • Only Tasks & Timesheet
  • MRP Orders
  • BOM & MRP Orders

Setup & Configuration

Prerequisites before Installation.

No prerequisites are required before the installation.

Configuration

Activate the developer mode.

Screenshots

Once the developer mode is activated, a new menu named "Clean Data" will visible.
Navigate to: Settings > Clean Data > Clean Data.
Click clean data menu for open wizard of clean data.

Data will be deleted only if the table exist in the database. For example, If purchase module is not installed, purchase checkbox will be visible on the popup but as the table doesn't exist it will have no effect.

Notes :

  • Do not deploy this module directly to the production environment. First, validate it in your staging environment, and once confirmed, proceed to production.
  • Data is deleted via SQL query, and you will not be able to restore it.
  • This module supports only core objects/tables of the odoo and not custom objects/tables.
